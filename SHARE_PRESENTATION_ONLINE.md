## 🆘 TROUBLESHOOTING

### GitHub Pages Not Working
**Problem:** "You don't have permission"
**Solution:** 
- Check repo is public
- Enable GitHub Pages in Settings
- Wait 2-3 minutes

### URL Shows Raw Code
**Problem:** Seeing HTML instead of presentation
**Solution:**
- Use GitHub Pages URL (not raw URL)
- Clear cache and refresh
- Check file is presentation.html (not .py)

### Slow Loading
**Problem:** Takes >10 seconds
**Solution:**
- First load is slower
- Refresh browser (faster 2nd time)
- Check internet connection
- Try different browser

### Mobile Not Working
**Problem:** Doesn't work on phone
**Solution:**
- Site is fully responsive
- Try rotating device
- Clear browser cache
- Try different phone
