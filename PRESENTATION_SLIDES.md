## Slide 9: Data Flow Pipeline

```
User Input (Income + Expenses)
        ↓
[BEFORE_SESSION_INIT Hook] → Load user context
        ↓
Validation Engine (Governance) → Check rules
        ↓
[BEFORE_ANALYSIS Hook] → Pre-analysis setup
        ↓
EXPENSE ANALYZER SKILL ↔ [Pattern Detection]
        ↓
[AFTER_ANALYSIS Hook] → Save to database
        ↓
RECOMMENDATION GENERATOR SKILL
        ↓
[AFTER_RECOMMENDATION Hook] → Log suggestions
        ↓
COMPLIANCE CHECK → Ensure financial advice is safe
        ↓
OUTPUT LAYER:
├─ Dashboard Metrics
├─ Chat Responses
├─ Recommendations List
└─ Alerts/Notifications
        ↓
OBSERVABILITY:
├─ Logging (Every step)
├─ Metrics (Performance)
└─ Tracing (Full session)
```

- Hooks enable extensibility at key points
- Governance is built-in, not an afterthought
